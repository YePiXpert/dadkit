# DadKit 3.4.7 发布说明

发布日期：2026-08-12

Android：versionCode 20 / `com.dadkit.mobile`

## 稳定性与数据安全

- 本机数据写入改为更严格的原子提交，清单、规划、里程碑和同步合并不再留下半新半旧状态。
- 补齐存储容量、持久化失败和主题偏好写入告警；数据库或存储不可用时提供可恢复错误页面。
- 宝宝事件和快照写入增加回滚与失败提示，照片读取、对象 URL 和缓存生命周期更可靠。
- 清单草稿跨刷新保留，新增对话框、宝宝快捷记录和设置子页的返回路径更稳定。

## PWA 与离线体验

- Service Worker 首次安装只预取入口壳，其余核心路由在后台逐步补全，避免安装被大批路由阻塞。
- 首访路由和已加载 Next.js 资源会明确写入缓存，离线就绪状态可诊断。
- Chromium 与 WebKit 的独立 PWA 回归隔离执行，覆盖宝宝记录、规划、医院档案、同步设置和首次引导。

## WebDAV 与同步

- WebDAV 同源代理升级为二进制请求体和元数据头，避免大型 JSON 再次转义造成内存与体积放大。
- 请求、响应统一限制为 32 MiB，并加入 30 秒超时、流式响应截断和更严格的并发限制。
- 大文件、网络中断、远端错误与代理错误均返回可操作提示；下载和上传不会无限等待。
- 同步与备份生成在异步读取后重新获取最新本机域，降低并发编辑遗漏风险。

## 验收结果

- ESLint、TypeScript、Vitest 95 个文件 / 631 项用例通过。
- Web 生产构建与全部性能预算通过；`/settings` 首屏为 169.3 KiB。
- Playwright Chromium/WebKit 回归 73 项通过、1 项按设计跳过；WebKit 独立 PWA 用例额外连续复跑 3 次通过。
- Android 静态导出与 594 项公开资源校验通过，其中含 144 张物品图和 33 张成长图。
