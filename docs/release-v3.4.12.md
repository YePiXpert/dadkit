# DadKit 3.4.12 发布说明

发布日期：2026-08-19

Android：versionCode 25 / `com.dadkit.mobile`

## 首页与清单体验

- 首页改为孕周/宝宝状态头、六项快捷入口与紧凑准备进度，减少重复的大型进度卡。
- 清单页改为紧凑进度卡、吸附筛选与收敛后的搜索/批量操作，分类页支持卡片和紧凑列表切换并持久化偏好。
- 「显示物品说明」收进分类页头图标，不再单独占据一整行。
- 出发页改为紧凑确认列表；成长时间表默认聚焦当前阶段，可按需展开全部 33 周。
- 工具页新增清单设置、备份恢复、家庭同步和帮助反馈入口。

## Android 页面热更新

- Android WebView 改为直接加载 `https://dadkit.505f.com`，页面、样式与业务功能随服务器部署，在下次启动时自动生效。
- Service Worker 对页面导航采用联网优先、缓存兜底；成功联网使用一次后，断网仍可打开最近缓存的主要页面。
- 当前会话不会因服务器发布而强制刷新，避免打断编辑和记录操作；首次使用或清空应用数据后的第一次启动仍需联网。
- 移除 APK 内的完整 PWA 静态导出与图片副本，缩小安装包并取消 Android 专用前端构建分支。

## 原生兼容与安全

- 保持原 HTTPS origin，因此覆盖安装后 Cookie、localStorage、IndexedDB、家庭数据和同步配置继续原地使用。
- 原生数据迁移改为运行时检测，仍支持从 3.4.2 原生版本迁移遗留数据。
- 文件选择、主题同步、外链限制、返回键和应用内更新桥保持不变。
- 原生新版继续限定从生产域名下载 APK，校验 SHA-256 后才调用系统安装界面。

## 发布与验收

- Android 发布校验改为确认 APK 不包含 `assets/www`，同时验证包名、生产域名、版本、更新地址白名单、签名和校验能力。
- 页面版本与 Android 外壳 versionCode 在「我的 → 关于 DadKit」中分开显示。
- Web/PWA 先于过渡 APK 部署；旧版 APK 继续使用其内置页面和兼容 API，不受服务器切换影响。
- Web typecheck、lint、生产构建与 626 项 Vitest 均通过；首页、清单、出发、成长和工具页已完成移动/桌面浏览器核验。
