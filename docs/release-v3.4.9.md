# DadKit 3.4.9 发布说明

发布日期：2026-08-18

Android：versionCode 22 / `com.dadkit.mobile`

## 家庭同步加入策略

- 加入家庭时默认使用远端家庭数据替换本机业务数据，防止新设备在打开邀请前就把本机内容合并到家庭空间。
- 新增“合并本机数据”选项；只有用户主动选择后，才会保留并合并两端数据并上传结果。
- 加入前自动创建本地恢复点。远端替换不会覆盖本机设备偏好和物品照片。
- 首次拉取暂时失败或家庭数据尚未准备好时保留所选策略，后台重试不会意外切换为合并上传。

## Origin 安全策略

- 支持通过 `DADKIT_PUBLIC_ORIGIN` 配置唯一公开来源。
- 支持通过逗号分隔的 `DADKIT_TRUSTED_ORIGINS` 配置精确可信来源。
- 拒绝通配符、相似域名、跨站请求和生产环境 HTTP 别名。
- Docker Compose、首次部署及升级脚本均会透传 Origin 配置。
