# DadKit V2 设计系统

V2 的界面目标只有一个：让用户打开后立刻知道“还差什么”，不先完成任何表单。

## 信息架构

- 主导航恰好两个：`清单 /`、`数据 /settings`。
- `/` 直接渲染唯一的 `ChecklistWorkspace` 清单入口。
- `/settings` 只承载 JSON、WebDAV、本地恢复快照和清单重置，不再承担个人中心或工具集合职责。
- 隐私与支持是数据页的辅助入口，不增加第三个主导航项。

## 数据页结构

- 顶部先说明清单默认只保存在当前浏览器，并摘要显示本地恢复点和 WebDAV 状态。
- JSON 手动备份是默认可见的主操作；导入输入区仅在用户主动选择时展开。
- WebDAV 是高级手动备份能力，默认折叠；上传、下载、冲突和错误反馈必须留在同一面板内。
- 本地恢复快照与清空重建分开呈现；清空是危险操作，必须二次确认并在按钮附近反馈结果。
- 隐私政策、支持入口和版本信息使用轻量页脚，不再建立“关于”工具卡。
- JSON、本地快照和 WebDAV 只备份清单数据，不包含物品照片、WebDAV 连接配置或凭据。

## 清单结构

- 页头为居中小标题；新增物品入口是右下角的黑色圆形 FAB（参考 App 同款）。
- 顶层只提供 `全部 / 待购买 / 待装包` 三个视图，数量必须与可见 selector 共源；视图切换使用珊瑚红填充胶囊 tab。
- 内容按证件、妈妈、宝宝、陪产人、返家准备和临出门六类分组。
- 行的首要动作是状态推进；默认只展示名称、数量、一句话说明、状态和缩略图。
- 编辑、标记不需要、删除、完整说明与本机照片放入行详情。
- 同名新增物品合并数量，不创建第二条可见记录。

## 状态语言

- `待处理`：还未备齐。
- `已备好`：已经买到、洗好或家中已有，下一步装包。
- `已装包`：已经进入固定行李位置。
- `不需要`：当前家庭明确不准备；仍可在“全部”恢复。

实现可以兼容旧内部状态，但界面不得暴露七状态下拉框或工程字段。

## 色彩与层级

视觉语言复刻参考 App「母婴清单」：暖米白底、纯白大圆角无边框卡片、陶土珊瑚红主色。

| 角色 | HSL | 用途 |
| --- | --- | --- |
| background | `33 43% 96%` | 暖米白页面底 |
| foreground | `20 14% 16%` | 暖深棕黑正文 |
| card | `0 0% 100%` | 白色内容卡（大圆角、无边框） |
| primary | `14 56% 50%` | 陶土珊瑚红主动作与选中态，白色小字对比度不低于 4.5:1 |
| secondary | `22 55% 92%` | 浅蜜桃提示、选中淡底 |
| muted | `36 30% 93%` | 浅米灰说明泡、计数 chip |
| border | `30 24% 90%` | 仅用于细分隔线 |

分类卡头部图标块按语义使用柔和粉、杏、薄荷、蓝、紫等背景；物品卡插画区统一使用浅米灰底。`ChecklistItemIllustration` 通过内联注册表提供一对一原创 SVG 构图；不得直接复制参考 App 的图标或素材。

## 尺寸与排版

- 移动端内容宽度以 `mobile-shell` 为基准，桌面端保持单列主清单，避免把 Todo 拉成后台表格。
- 主要点击目标至少 44×44px。
- 页面标题 `text-xl` 至 `text-2xl`，内容标题 `text-sm font-semibold`，说明 `text-xs leading-5`。
- 卡片使用 `rounded-2xl/3xl`、无边框和一档轻阴影；不用大面积装饰插画。
- 文字必须允许换行，不能用截断隐藏物品名称或重要说明。

## 照片

- 照片只帮助用户辨认自家物品，不承担商品推荐。
- 上传后最长边压缩到 800px 左右，以 JPEG 约 0.8 存入 IndexedDB。
- 列表只显示约 36px 缩略图；替换和删除在行详情内。
- 照片不进入 JSON 或 WebDAV 备份，界面需明确说明“照片仅存本机”。

## PWA

- 只维护 Web/PWA 发布链路；manifest、Service Worker、离线页和安装入口必须可独立工作。
- 不新增 Android、iOS、Capacitor 配置、脚本、依赖或商店交接资产。
- 新版本需更新 Service Worker cache name，保证已安装 PWA 能切换到新壳。

## 边界

- 不做医疗判断，不把模板描述成医院官方要求。
- 不放品牌、价格、购物链接或导购内容。
- 不引入账号、家庭组实时同步或默认云上传。
- 不重新引入首页仪表盘、四柱进度、强制向导、五项导航、七分组顶层 tab 或复杂筛选器。
