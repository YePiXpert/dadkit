# DadKit 3.4.4 发布说明

发布日期：2026-08-08

Android：versionCode 17 / `com.dadkit.mobile`

## 主要更新

- APK 检测到新版本后，可在应用内下载并显示实时进度。
- 下载入口只接受生产站 HTTPS 更新端点和合法的 64 位 SHA-256，并限制安装包体积；下载完成后校验通过才调起 Android 系统安装界面。
- 首次安装来源授权通过 Android「安装未知应用」设置完成；原生桥不可用时继续使用普通下载链接。
- 家庭邀请统一分享完整加入链接；系统分享不可用时保持复制兜底。
- 同步会话失效横幅可关闭，不再持续遮挡界面。
- 启动时尽力申请浏览器持久化存储，降低系统自动清理本机数据的概率。
- 旧版 localStorage 恢复点会自动迁移到 IndexedDB，迁移失败时保留原件并在下次重试。
- v6-v9 备份允许未来版本新增未知顶层字段，同时仍严格校验所有必需字段。
- 收敛备份页样式类，并补齐清单可用性、空态、贴纸动效和 UI 一致性测试。

## APK/PWA 一致性

- Android APK 继续由当前 Next.js PWA 源码静态导出，不维护第二套产品界面。
- 发布包必须包含 594 项公开资源、144 张物品图、33 张成长图及完整页面入口。
- `scripts/validate-android-release.mjs` 同时校验版本、路由、资源哈希、应用内更新权限、FileProvider、SHA-256 和系统安装桥。

## 验收结果

- ESLint、TypeScript 类型检查通过。
- Vitest：93 个测试文件、611 项用例通过。
- Web 生产构建及全部性能预算通过。
- Playwright：Chromium/WebKit 共 69 项通过，1 项按设计跳过。
- `npm run android:bundle` 与 Android 发布校验通过。

## 发布后真机检查

自动化和 Android 构建层已覆盖下载桥、进度状态、哈希校验、FileProvider 与安装 Intent。正式发布后仍需在真机用旧版 APK 完成一次「发现更新 → 下载 → 首次授权 → 系统安装 → 覆盖升级」冒烟验证。
