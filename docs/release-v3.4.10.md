# DadKit 3.4.10 发布说明

发布日期：2026-08-18

Android：versionCode 23 / `com.dadkit.mobile`

## 邀请链接与短口令

- 每条家庭邀请同时生成邀请链接和 `XXXX-XXXX` 短口令，方便跨设备输入或直接分享。
- 链接与短口令属于同一条一次性邀请，共享有效期、撤销状态和使用状态；任一方式加入成功后另一种方式立即失效。
- 服务端不保存短口令原文，仅保存加盐哈希和定位摘要；加入接口继续执行 15 分钟最多 20 次的客户端限流。
- 分享内容同时包含链接和短口令，管理页分别提供复制链接、复制口令和统一分享操作。

## 同步体系收敛

- 删除旧“家庭名称 + 同步码”创建和加入流程、旧邀请接口及旧会话升级接口。
- 删除浏览器 localStorage 中的旧 token 会话兼容和 Authorization Bearer 认证，仅保留 HttpOnly Cookie 会话。
- Android 原生迁移桥不再读取或迁移旧同步 token；业务数据与既有备份格式迁移仍然保留。
- 加入家庭时继续提供“使用家庭数据”和“合并本机数据”两种明确选项，并在操作前创建本地恢复点。

## 数据保护与验收

- 发布前已只读确认线上“小美”为随机空间 V2、业务数据 V9；部署时先独立备份该空间再清理旧格式空间。
- ESLint、TypeScript、Vitest 95 个文件 / 623 项用例通过。
- Web 生产构建通过，构建路由中不再包含旧同步 API。
- Chromium 同步管理流程 4 / 4 通过，覆盖短口令加入、设备角色、离线重开和空间删除。
