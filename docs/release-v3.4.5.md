# DadKit 3.4.5 发布说明

发布日期：2026-08-08

Android：versionCode 18 / `com.dadkit.mobile`

## 修复内容

- Android WebView 宽度低于 360 CSS 像素时，单列物品卡图片由 4:3 调整为更紧凑的 16:9；360 像素以上的双列卡片继续保持 4:3。
- 统一处理静态导出路径的末尾斜杠，`/checklist/` 不再被误判为清单详情页。
- 所有清单分类页恢复常驻五项底部菜单，并保持「清单」入口高亮。
- 分类页增加底部导航安全区，新增物品按钮固定在菜单上方，不再遮挡菜单或卡片操作。
- 删除已无调用方的无导航浮动按钮样式。

## APK/PWA 一致性

- Web、PWA 和 APK 继续使用同一套 React 组件、响应式样式和导航判断。
- Android APK 由当前 PWA 源码重新静态导出，不维护第二套清单界面。
- 发布校验继续逐文件核对 594 项公开资源、144 张物品图、33 张成长图和全部页面入口。

## 验收结果

- 335×745 Android 手机视口实测：图片由约 268×201 缩至 268×151，底部菜单可见且「清单」正确高亮。
- ESLint、TypeScript 类型检查通过。
- Vitest：93 个测试文件、611 项用例通过。
- Web 生产构建及全部性能预算通过。
- Playwright：Chromium 35 项通过；WebKit 34 项通过、1 项按设计跳过，跨标签一致性用例首次偶发超时后单独重跑通过。
- `npm run android:bundle`、Android 发布资源校验和 Gradle APK 构建通过。

## 发布后真机检查

建议从 3.4.4 正式包完成一次应用内更新，并在清单首页及任一分类页确认底部菜单、图片高度和新增按钮位置。
