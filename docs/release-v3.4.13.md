# DadKit 3.4.13 发布说明

发布日期：2026-08-19

Android：versionCode 26 / `com.dadkit.mobile`

## 家庭分工下线

- 删除家庭分工与采购规划页面、首页摘要卡、物品规划弹窗及全部入口。
- 首页原第六项快捷入口替换为「备份与恢复」；工具页补齐「清单设置」与「家庭成员」。
- 物品详情不再显示或编辑负责人、预算、购买渠道、截止日期及备注等规划信息。
- `/planning` 保留兼容跳转，旧收藏或历史链接会回到工具页。
- 家庭成员仍用于宝宝事件记录人和家庭同步，相关能力不受影响。

## 数据兼容

- 当前可移植数据格式升级到 v10，不再保存、导出、合并或同步 `planning` 字段。
- 旧 v7-v9 备份与同步数据仍可导入；历史 `planning` 字段完成格式校验后会被忽略。
- 向仍使用 v7-v9 协议的旧客户端提供空规划占位，避免旧客户端因缺少字段而拒绝同步。
- 清理本机旧规划存储，不迁移或保留已下线功能的数据。

## 验收

- TypeScript、ESLint、生产构建与性能预算检查通过。
- 87 个 Vitest 文件、576 项测试全部通过。
- Chromium 覆盖首页、工具页、家庭成员、跨标签同步和旧链接跳转等关键流程。
- 移动端与桌面端截图确认首页、工具页和物品详情布局正常且无家庭分工内容。
