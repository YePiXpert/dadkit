# DadKit 3.4.11 发布说明

发布日期：2026-08-18

Android：versionCode 24 / `com.dadkit.mobile`

## 设置信息架构收敛

- 「我的」设置页从 5 个平铺入口重组为两组：家庭协作（家庭同步、家庭成员）与数据与偏好（清单设置、备份与恢复），并带小节标签。
- 「关于 DadKit」并入「我的」页底部，直接显示当前版本并可手动检查更新；原 `/settings/about` 路由保留为 307 跳转到 `/settings`，旧链接、Service Worker 预缓存与 APK 内置页面不受影响。
- 安装到桌面入口、外观切换保留在「我的」页，位置不变。

## 布局与尺寸

- 新增共享入口卡片组件 `LinkEntryGrid`：移动端为紧凑单行卡片（取消 96px 最小高度），桌面端（≥640px）自动切换为双列磁贴；设置页与工具页统一使用。
- 子页面页眉（`PageHeader`）整体压缩：返回按钮 48→44px，标题与副标题字号收窄，副标题限宽居中平衡换行。
- 首页「家庭分工与采购」摘要卡改为标题行 + 整行描述，文字不再被右侧按钮挤压换行。
- 桌面顶栏从 672px 窄条加宽到全宽（max-w-6xl），阴影改为细分隔线，高度 72→64px。

## 配色

- 危险色从与主色相近的砖红（色相 3°）调整为深绯红（色相 350°），「永久删除」「重建清单」等危险操作与珊瑚主色按钮一眼可辨；浅色与深色主题同步更新。
- 其余暖奶油底色 + 珊瑚主色体系保持不变。

## 验收

- `/settings` 页因并入关于卡片，性能预算由 170 KiB 调整为 190 KiB（原 `/settings/about` 单独占 200 KiB 预算，合并后总量下降）。
- ESLint、TypeScript、Vitest 95 个文件 / 623 项用例通过。
- Web 生产构建与 Android 静态导出（含重定向页）均通过。
- Chromium 移动端 e2e 7 / 7 通过，覆盖「我的」页版本显示与手动检查更新流程。
